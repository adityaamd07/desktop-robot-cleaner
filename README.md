# desktop-robot-cleaner
The goal of this project is for myself, a rising sophomore mechanical engineering student, to create a fully autonomous desktop robot that is able sweep large debris off a smooth surface, and then sanitize said surface. The robot should operate in two stages: a sweeping stage that sweeps away any large debris off the surface. The robot should then switch to a clean cleaning pad, and sanitize surface. All of the above should be able to be done without human interaction. 

This is obviously very ambitious for someone with zero experience in design or electronics. Although I have experience in C++, this will still prove to be a challenge. Thus, I have divided this project into seperate phases, each with its own goals.

## Phase one: Robot driving mechanism

The goal of this phase is to create a fully functioning drivable robot with a sweeping mechanism and a nozzle to spray out cleaning solution. The robot should be able to drive in all four cardinal diretionswith human input, and should be able to turn the sweeping mechanism and the spray on and off with human input. 

**Status:** ongoing 

## Phase two: Changing Pad

The goal of this phaase is to design a mechanism to replace the cleaning pad that the robot uses for sweeping and sanitizing. Note that at this point, this phase should be purely focused on removing the dirty pad and replacing it with the clean one, not anything related to the autonomous driving.

**Status:** not started

## Phase three: Autonomous driving

This phase will involve fully designing and testing my autonomous driving system. I will consider this phase, and therefore the project, a success if the robot can autonomously sweep the entire surface, change its cleaning pad, and sanitize the surface without falling off the edge of the desk, crashing, stopping for a super prolonged period of time, or crashing into any of the onjects on the surface. 

**Status:** not started
